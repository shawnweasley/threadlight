# 实现来源

Threadlight 的需求来自使用者对菜单栏状态监控的一系列实际调整：每个对话一个稳定编号，只显示运行/结束，保留完成未读，兼容 Claude Code，并提供可横向缩放的置顶任务列表。

此前曾基于 `yuriipalam/codex-status-bar` 做过原型。开发过程中已经阅读和对比过该项目，因此这里不宣称是开发者从未接触参考实现的隔离开发。

本仓库在新目录中建立了新的 SwiftPM 工程、域模型、状态账本、数据适配、UI 组件、回归测试、CI 和打包脚本。没有把旧工程的 Swift 源文件或构建脚本复制进来，也不依赖旧应用运行。macOS/Swift 的通用启动代码、标准格式与通用 API 调用可能天然相似，行相同比例不用于判断著作权归属。

唯一明确沿用的文件资源为使用者指定保留的 Codex SVG 标识与 ICNS 图标，均在 `THIRD_PARTY_NOTICES.md` 列出路径、来源版本与授权边界。

MIT 许可证覆盖本工程的程序代码，不将第三方商标或图标重新授权为原创资产。参考项目在此列作需求演进和资源来源的致谢。
